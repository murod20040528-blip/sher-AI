# Sher-AI 📝
Sun'iy intellekt yordamida o'zbek tilida she'rlar yaratuvchi va tahlil qiluvchi zamonaviy veb-ilova.

## Texnologiyalar
- **Framework:** Next.js (App Router)
- **Til:** TypeScript
- **Dizayn va uslublar:** Tailwind CSS & Shadcn UI
- **Deployment:** Vercel

## Loyihani ishga tushirish
1. Kutubxonalarni o'rnating:
   ```bash
   npm install
   ```
2. Mahalliy serverni ishga tushiring:
   ```bash
   npm run dev
   ```
3. Loyihani yig'ish (build):
   ```bash
   npm run build
   ```
